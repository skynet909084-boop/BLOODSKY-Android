# Задание для Work — полный интерактивный аудит KaScada Smart Craft 1.0.7 (107)

Используй приложенный оригинальный APK `KaScada Smart Craft 1.0.7 (08.02.2026).apk`, карту `kascada_107_full_function_audit.md`, JSON `kascada_107_full_function_test_matrix.json` и оригинальную встроенную справку. Цель — **исследовать весь доступный функционал оригинального Android-приложения**, не только главное меню и Create, и подготовить точную спецификацию для проекта BLOODSKY.

1. Проверь наличие управляемого Android-эмулятора/облачного устройства и возможность установить APK. Если устройства или установки нет — не имитируй клики, не объявляй тесты PASS. Сделай статический аудит доступных компонентов и явно обозначь BLOCKED. Не загружай APK в публичное хранилище без согласия.
2. При реальном запуске запиши устройство, API Android, ориентацию, версию 1.0.7/107, разрешения и лицензионный статус. Никаких покупок или отправки данных реальным получателям.
3. Выполни **каждый** пункт JSON-матрицы (или документируй техническую причину, почему не выполнен). Обходи все меню, вкладки, диалоги, контекстные меню, компоненты HMI, компоненты Logic/FB/VAR/EL, настройки и экранные сценарии.
4. Проверяй одиночные и долгие нажатия, жесты, перетаскивание, изменение размеров, возврат, отмену, сохранение, выход/перезапуск, импорт/экспорт, работу и отсутствие разрешений, невалидные данные, ошибки соединений.
5. Для аппаратных функций используй только безопасные тестовые Modbus-серверы/устройства и аккаунты; где устройство/лицензия/доступ отсутствуют — BLOCKED, не PASS.
6. Сохраняй по каждому пункту: ID теста, точные шаги, скриншот/кадр или видео, результат, статус PASS/FAIL/BLOCKED, зависимость от лицензии, цитату ресурса/метода при необходимости.
7. Результат: карта всех экранов и переходов, каталог компонентов и их свойств, контракт взаимодействия с регистрами и сетью, перечень ошибок/ограничений, таблица сопоставления с BLOODSKY, приоритизированный backlog и ссылки на подтверждающие материалы.
8. Следуй задаче автономно, без остановок после первых экранов; работай последовательно по всей матрице. Никогда не выдавай статический анализ за реальные нажатия на телефоне.
