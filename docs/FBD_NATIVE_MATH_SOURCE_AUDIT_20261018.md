# Original Craft arithmetic and change blocks — audit queue

Source pinned to `reference/craft-reference.zip` SHA256 `316da0335dc4ea0c8f2d8c14550118ba33bd0e95d7c926f67ed848429c554cdd`. This PR extends the independent, bounded **read-only** FBD Java evidence generator with optional classes: `FB_ARITHMETIC_INT`, `FB_ARITHMETIC_FLOAT`, `FB_COMPARE_FLOAT`, `FB_CHANGE_I`, `FB_CHANGE_F`, as well as original math-converter candidates `SIN`, `LOG`, `ABS`, `IntToFloat`, `FloatToInt`, `WordToFloat`. The first five are the immediate priority because they correspond to still-disabled original FBD palette controls.

The source archive includes 40 unique original palette view tags. Before this research increment **14** had verified enabled click actions (AND, OR, XOR, TIMER, POW, SIN, ABS, IntToFloat, FloatToInt, RS, T, CTU, SEL, COMPARE) and **26** remained deliberately disabled. Some names are already backed by BLOODSKY generic numeric operations, but name matching is not semantic proof. The original `FB_POW`/ `FB_MOVE` Java `f()` bodies were observed empty in pinned source; `FB_ARRAY` accesses application-level side effects and `FB_MACRO` depends on variable namespaces. None can be responsibly enabled solely from their captions.

The evidence artifact `original-fbd-runtime-evidence.json` records source SHA256, direct superclass, imports, matched method/branch fragments and bounded execution snippets. Optional candidates missing from the archive are omitted rather than fabricated. Tests use synthetic ZIPs and cannot execute untrusted Java. The 64 MiB archive-size and 5,000-entry safety guards still apply.

**Required next acceptance:** inspect this job's actual artifact for original f() modes, input/output type and overflow behavior, original source class constructors and pointer dependencies; only then add separately versioned native Integer/FLOAT/change blocks with JUnit and real Android UI if supported. Existing source palette disabled items must remain disabled until source-concordant runtime has passed current FBD #76 feature CI. This audit PR does **not** implement any new operator, change stable `main`, or claim visual parity.
