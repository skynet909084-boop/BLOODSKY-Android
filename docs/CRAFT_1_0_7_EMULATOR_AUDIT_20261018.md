# Эмуляторный аудит исходного KaScada Smart Craft 1.0.7

Дата прогона: 2026-10-18. Пакет: `ru.kascada.modbus`. Эмулятор: Android 11 / API 30, без сети.

## Текущее состояние

Исходный APK восстановлен из полного Apktool-декомпила, подписан debug-ключом, установлен и запущен в эмуляторе. Сборка и проверка подписи успешны.

Первый проход был прерван на системном запросе доступа к файлам и дал только стартовый экран. В следующем проходе тестовые разрешения файлов, геолокации, аудио и камеры были предварительно выданы в изолированном эмуляторе. Промежуточный проход №11 собрал 128 снимков и accessibility-деревьев до ручного улучшения обходчика; поскольку его остановили до конца, итоговый JSON с полным графом действий и журналом AndroidRuntime не был записан. Проходы №12 и №13 отменены до финального JSON, чтобы ускорить обход и исправить тестовые данные. Полный проход №15 ожидает запуска; ограничения: 180 состояний, глубина 7, очередь 900 путей. Он также пытается нажимать видимые ImageView/TextView палитры, которые не помечены Android как clickable.

Промежуточные скриншоты из прерванного прохода сохранены в артефакте GitHub Actions run 39168081863 (artifact 12153170860; срок хранения до 2026-10-25). Полный decompile-артефакт исходного запуска: run 38600957172.

## Что исправлено в тестовом проходе

- APK строится с нормализацией шести недопустимых имён ресурсов `$avd_*`; их ссылки нормализуются одновременно, чтобы сохранить соответствия ресурсов.
- Сборщик обходит доступные видимые кнопки и поля, сохраняет PNG и XML. Лимиты и оставшаяся очередь включаются в итоговый JSON.
- Исключена бесконечно разрастающаяся ветка Android Back; обходчик стал быстрее и фиксирует доступные прямые переходы.
- Тестовые текстовые значения выбираются по подписи поля; для имени проекта используется `CraftAudit`, адреса и порт получают отдельные безопасные значения. После ввода клавиатура скрывается.
- Wi-Fi и мобильные данные выключены. Это UI-аудит без настоящего Modbus-устройства; Bluetooth/USB оборудование эмулятором не подменяется.

## Ограничения и следующие результаты

Этот файл пока является промежуточным checkpoint, а не завершённым отчётом функционального теста. Не считать подтверждёнными все действия и все компоненты: старый проход остановлен до создания итогового JSON, а некоторые пути в нём использовали некорректные тестовые значения.

После завершения GitHub Actions run 39172534989 сюда будут добавлены число уникальных экранов и переходов, оставшаяся очередь, результаты создания тестового проекта, проверки меню/компонентов, журнал AndroidRuntime и ссылки на итоговый артефакт. Физические Wi-Fi/Modbus TCP, RTU-over-TCP, Bluetooth SPP и USB проверяются отдельно от визуального эмулятора.
