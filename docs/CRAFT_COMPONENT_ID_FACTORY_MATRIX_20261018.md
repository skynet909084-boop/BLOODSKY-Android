## Выводы и исправления к прежней таблице

1. Неполный `deleteView(View)` switch не является источником полной карты. Он не содержал 16/17, однако фабрика `m()` подтверждает ID 16 = GIF и ID 17 = multi-state image.
2. В фабрике `m()` не найден ID 3. Это зафиксировано как unresolved, а не как «ID 3 не существует».
3. Реестр класса `CustomComponents.a0` для ID 27 должен называться recognition/распознавание по исходным строкам `custom_voice_recognition` и `textVoice0…15`; это не доказательство TTS.
4. По текущему importer отдельные точные визуальные/поведенческие mapping есть только у части ID. Неизвестные ID сохраняются fail-closed, но это совместимость/сохранение данных, а не паритет.
5. Для полного аудита остаются source/Smali cross-reference, per-ID свойства редактора и runtime, визуальное сравнение на равной плотности и устройство/транспортные acceptance.



## Craft ID 8 — imported numeric-input implementation and remaining acceptance

Source: `CustomComponents/i.java` and `mbCanvas.java` from the pinned decompilation artifact `11912849123`; handler call-sites cross-checked in `apktool/smali/ru/himik/nightscream/kascada/mbCanvas.smali`.

- Original view is centered Canvas text. It defaults to the SF digital readout font, can use the system font, and has an independent frame toggle.
- `connectionInfo`: `posDeviceNetworkInList, addressRegister, min, max, password`. `other`: `numScreen, type, typeInt, countNumAfterPointEditNumber, fontChange, enableFrameEditNumber, timeZ`.
- `type=0` is integer entry; original commit parses Float32 then truncates to integer. `typeInt=0` displays unsigned UINT16; `typeInt=1` signed INT16. `type=1` writes Float32 using two consecutive registers. Decimal digits cap the displayed value.
- Original dialog limits value text to 15 characters and password text to 10, checks password, rejects empty or out-of-range values, and applies separate integer/Float32 write paths. Decompiled handler at `mbCanvas.smali:65515–66050` confirms password gate, min/max checks, integer request, and Float32 multi-register request.
- BLOODSKY maps ID 8 to `Числовой ввод Craft` and imports these settings. Device slots remain inactive until explicitly remapped. For global/system slot 100, imported integer values read the local system bank with UINT16/INT16 display; writes require operator enablement and are limited to user registers 10–1999. Float32 system bindings and writes to service registers 0–9 remain disabled. Craft passwords are not copied into active secret storage; a password-protected import must be assigned a new password, encrypted with Android Keystore.
- Pure helper and importer tests cover source-field mapping, fail-closed bindings, UINT16/INT16 bounds, integer truncation, Float32 range, precision, register width, signed local words, explicit write opt-in, and disabled system modes. Exact-head run #1129 on commit `7bb8bb3` exposed two test-fixture assertion errors; corrected fixtures await a new CI run. Full Android 11 UI smoke #763 passed on `7bb8bb3`, but ID8 UI comparison and device acceptance remain open.

Remaining acceptance: compare the rendered field and dialog against the original at the same viewport and density; verify keyboard behavior and Float32 register read/write with a mock Modbus TCP peer; verify encrypted password create/read/clear on Android; then run the complete UI profile. This ID is not marked visually or device-accepted.
